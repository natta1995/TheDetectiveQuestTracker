
## 🛠 How to Run the Project

1. Clone or download the repository.  
2. Open the project in any C# development environment (e.g., Visual Studio or Rider).  
3. Run the project using **Run** or by starting the main program file.
4. When prompted, create a password to start the game:
	
* Lenght : At least 6 characters.
* Uppercase : At least one uppercase letter (A–Z).
* Digit : At least one digit (0–9).
* Special Character : At least one special character.



## Overview

This is a text-based quest game — a personal passion project.
The game takes place in London in 1936. You play as a wealthy upper-class citizen living in an elegant apartment with your butler George. As you enjoy your pension days, an old friend from Scotland Yard contacts you and asks for your help with several cases.

How the Game Works

In the game, you take on different murder cases.
From the View Cases menu, you can travel to the specific crime scene. There, you can:

look around,

investigate clues,

interrogate suspects,

and make an accusation.

If you accuse the correct suspect, the case will be added to Solved Cases, which you can view in your office menu.
If you choose the wrong suspect, Scotland Yard takes over the case and you will no longer be able to play it.

Each case is categorized by priority level.
You will receive reminders by email when a case is running out of time.
If the time runs out completely, Scotland Yard will again take over the case and you will no longer be able to play it.

If the list in Add Cases is empty, or if you don’t want to play any of the available cases, you can always call your friend at Scotland Yard. He will provide you with two new case options to choose from
